# River Room: runnable project

This ZIP is independent of the supporting-files ZIP. It contains the Java source,
ACM library and license, and launch scripts. You still need JDK 17 or 21 installed.

1. Extract this ZIP.
2. Open Terminal or Command Prompt inside `River_Room_Run`.
3. On Mac/Linux run `bash run.sh`.
4. On Windows Command Prompt run `run.bat`; in PowerShell run `./run.bat`.

The scripts compile the source into `out` and launch the desktop game. Both `java`
and `javac` must be available. Run locally on a computer with a desktop display.
No tests or supporting documents are needed to launch it.

Choose a difficulty, click Deal, then Check, Bet 20, or Fold. Wins earn cosmetic
coins. Use Buy / Equip to purchase a card style. This is a river-only prototype,
not a full match. Coins reset when the program closes.

The separate supporting ZIP contains the feasibility study, UML, full project
README, GitHub instructions, tests, and development scripts.
